# 批量水印工作台 · Batch Watermark Studio

> 一次配置，批量给所有照片加同一套水印；支持预设位置与预览拖拽定位，可调输出分辨率，一键导出全部结果。
>
> **开发者：KYO4926** · Copyright © 2026 KYO4926 · [MIT License](LICENSE)

一款 macOS 原生应用（Swift + WKWebView），界面本身是一份自包含 HTML。所有图片处理都在**本机浏览器内核的 Canvas 中完成，不联网、不上传、不内嵌任何用户数据**。

---

## 下载与使用

- 前往本仓库的 **Releases** 下载 `批量水印工作台.dmg`，打开后把 App 拖进「应用程序」（也可以直接双击运行，无需安装）。
- 仓库内也保留了一份构建产物：`dist/批量水印工作台.dmg` 与 `dist/批量水印工作台-macOS.zip`。
- 只想快速试用网页版：直接用浏览器打开 [`app.html`](app.html) 即可，功能一致；在浏览器中下载走浏览器的普通下载流程。
- 要求：macOS 12.0 或更新版本。App 是 arm64 / x86_64 通用二进制，已做 ad-hoc 签名。首次打开如遇系统提示，右键 →「打开」即可。

## 功能

**以批量为核心**
- 一次导入几十张照片（点击选择、菜单导入，或直接把文件拖到窗口上），左侧队列显示每张的缩略图、原始尺寸与处理状态。
- 拖入或选择照片后会弹出**导入进度窗口**，实时显示「已完成 X / N 张」「正在导入第几张：文件名」和进度条；在原生 App 中还会先显示文件接收进度，导入结束后自动收起。
- 配置一次水印 → 「应用到全部照片」→ 用同一套参数快照逐张生成结果，全程有进度条与状态提示。
- 「一键批量导出 ZIP」把全部结果打包下载；导出前会自动补齐尚未处理的照片。配置一经改动会提示重新应用，避免导出旧结果。

**水印**
- 文字水印：内容、字体、字号、加粗、颜色、透明度、旋转、阴影、描边。
- 图片 / Logo 水印：透明 PNG 最佳，宽度按画面比例设定。
- 九宫格位置预设（四角、四边中点、正中央），也可在预览中**直接拖拽**水印，或用精确 X / Y 百分比定位；另有铺满画面的平铺模式。
- 所有尺寸与位置都按画幅相对比例存储，预设会按每张照片的自身尺寸独立换算，横竖混排也能对齐。

**改变分辨率与输出**
- 原始尺寸 / 按宽度 / 按高度 / 按最长边等比缩放 / 精确 W × H（裁剪填满、等比留白、拉伸三种适配），可限制「不放大」。
- JPG、PNG、WebP，可调画质、背景色与文件名后缀。
- 预览与最终导出使用同一套绘制函数，所见即所得。

## 从源码构建

```bash
# 需要：macOS 12+、Xcode Command Line Tools（swiftc）、Python 3 + Pillow（仅生成图标时需要）
./build.sh
```

构建脚本会：编译 `main.swift`（arm64 + x86_64 → lipo 通用二进制）→ 组装 `.app` bundle → ad-hoc 签名 → 生成 DMG（含「应用程序」快捷方式）与 ZIP。产物在 `dist/`。

图标由 `make_icon.py` 生成；若未安装 Pillow，可跳过该脚本，直接复用仓库里已有的 `AppIcon.icns`。

**内置自检**（会加载页面、跑一遍批量处理与导出后自动退出）：

```bash
WB_SELFTEST=1 dist/批量水印工作台.app/Contents/MacOS/WatermarkStudio
```

## 实现要点

- WKWebView 不会处理 `a.download`。因此网页侧把导出内容按 393216 字节（3 的倍数，保证分片 base64 拼接无中间 padding）分块，经 `nativeSave` 消息通道交给 Swift，由系统存储面板落盘并在 Finder 中选中；浏览器环境下自动降级为普通下载。
- 文件选择实现 `WKUIDelegate.runOpenPanelWith`（`NSOpenPanel` 多选）；原生拖放用 `WKWebView` 子类覆盖 `dragging*` 方法，把图片读成 base64 分片注入页面后构造 `File` 对象导入。
- ZIP 在网页侧自行实现（Store 模式 + CRC32 + UTF-8 文件名标记 + 合法 DOS 时间戳），不依赖任何第三方库。

## 隐私

- 源码、编译产物与 DMG 中**不含任何个人信息**：没有账号名、本机路径、邮箱、密钥，也没有示例照片。
- 应用不发起任何网络请求，不含统计、埋点或更新检查；照片只在内存中处理，从不离开设备。
- 构建时已清除 Finder 元数据（`.DS_Store` / `__MACOSX` AppleDouble），ZIP 使用 UTF-8 文件名标记，中文名在各类解压工具中都能正确还原。
- macOS 会在文件创建时由内核自动附加一个 3 字节的 `com.apple.provenance` 系统标记（值 `01 02 0a`），用户态无法移除；它只是系统级标签，不含账号、路径或任何个人信息。
